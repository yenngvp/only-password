# F023 e2e

Added `crates/onlypassword-cli/tests/e2e.rs`: one scenario test driving the real binary with
default KDF parameters (~7 s, ~35 invocations): init, add-login (TOTP, custom + hidden fields),
add-login --generate, add-note, re-read in fresh processes (lock/unlock), `passwd --rotate`
(old password exit 3), wrong key file exit 3, one-byte-flipped vault copies (non-zero exit, empty
stdout), export, fresh vault + import (own key file exit 3, first vault's key file works), and
list/get --show-secrets identical across vaults. Every capture is scanned for the passwords and
key texts; only `--show-secrets` and `generate` runs are exempt.
Nothing in production code or the spec changed; no spec issues or dep requests.
